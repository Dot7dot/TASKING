# TASKING 任務清單

自訂資料夾的任務紀錄頁，每完成一項任務就送一包卡包 🎁

🎮 **網址：<https://dot7dot.github.io/TASKING/>**（建議用手機開啟，可以「加入主畫面」當 App 用）

極簡風：白色背景、手寫字，每個資料夾都是用麥克筆一筆一筆畫出來的框（程式即時畫的 SVG，不需要圖檔）。
卡牌即時從 [卡牌製造機（card-uploader）](https://github.com/Dot7dot/card-uploader) 讀取，開卡包動畫和卡牌繪製沿用 [CardKing](https://github.com/Dot7dot/CardKing)。

## 用法

### 首頁：TASK LIST
- 一開始有三個資料夾：**LONG TERM**、**WEEKLY**、**REMINDER**（都可以改名或刪掉）
- 每個資料夾顯示前三項任務（未完成的排前面），右上角是完成數
- **點一下**資料夾進去看詳細內容
- **長按**資料夾可以拖曳，調整排列順序
- 右下角 **＋** 新增資料夾（建立後直接進入編輯模式）
- **往左滑**資料夾可以 **封存**：資料夾會移到「封存」區，主畫面上方的「資料夾｜封存」可以隨時切換
  - 封存區可以點開看內容（只能看不能改）
  - 在封存區再 **往左滑** 一次（或在資料夾裡按右上角的復原）就會放回主畫面原本的位置
  - 剛封存時下方提示可以直接按「復原」

### 每日任務（置頂、淡紅色的 DAILY 資料夾）
- 永遠置頂在主畫面最上面，不能拖曳、封存或刪除，但可以改名、新增／編輯項目
- **每天早上 8:00 重置**：勾選和能量條的進度全部歸零（App 開著跨過 8 點、或隔天才打開都會重置）
- 每天完成都會再送一包卡包；同一天取消再勾不會重送
- 右上角的卡包圖示是卡包區，數字是還沒開的卡包

### 資料夾裡
- 點右上角的 **鉛筆** 進入編輯模式，再點一次（✓）完成編輯
- 編輯模式可以新增三種項目：
  - **勾選框**：勾起來就算完成
  - **筆記**（bullet note）：一般的記事，沒有完成狀態
  - **能量條**：共 10 格，點格子表示目前的進度（再點一次同一格會退一格），**填滿 10 格就算完成**
- 每個項目都可以加一個 **備註框**（NOTE）
- 編輯模式裡：改資料夾名稱、改項目文字、按 ✕ 刪除、按住 ≡ 拖曳排序；在項目文字按 Enter 會在下面新增一個同類型的項目
- 點鉛筆左邊的 **複製** 圖示（兩個重疊的框），會在原本的資料夾後面複製出一個一模一樣的資料夾（項目、備註、勾選狀態、能量條進度、順序都一樣），
  並直接進入編輯模式方便修改；適合每週重複的清單或類似的任務
- 不在編輯模式時，也可以直接勾選、點能量條，或長按項目拖曳排序
- **完成的項目會自動沉到資料夾下方**，未完成的留在上面

### 獎勵：卡包
- **每完成一個項目就送一包卡包**（一包 2 張），會有一包卡包飛到右上角
- 每個任務只送一次：取消勾選再勾回去不會再送；複製資料夾後，副本裡的項目和原本的算同一個任務，
  原本或副本其中一個完成過就不會再送（在副本裡另外新增的項目才算新任務）
- 卡包統一是 **B00 系列**（深藍色底、黃字），只會開出卡牌製造機裡 `set` 為 `B00` 的卡
  - 卡牌製造機裡還沒有 B00 的卡時，卡包會先留著，新增卡牌後就能開
  - 以前拿到、還沒開的其他系列卡包，也會一起換成 B00

### 卡包區
- **我的卡包**：點卡包開包。卡包飛到螢幕前、越抖越大、撕開、一張一張翻牌
  - 有稀有度 ≥ 3 的卡會發出黃金光，≥ 4 會發出彩虹光；最稀有的卡留到最後翻
- **我的卡牌**：欣賞收集到的卡牌，可以依系列篩選；點開卡牌可以切換型態、按住拖曳看反光
- 抽卡機率和 CardKing 一樣：先依稀有度權重（1：100、2：40、3：12、4：4、5：1.5）決定稀有度，再從同稀有度裡平均抽；
  每張另外擲型態（一般 55%、金光亮面／霧面／金色邊框各 15%）
- 抽到已經有的卡（同型態）會標示「重複」，卡牌右上角顯示抽到幾次

## 部署到 GitHub Pages

1. 把這個分支合併到 `main`
2. 到 repo 的 **Settings → Pages**
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
4. 等一兩分鐘，網址是 `https://dot7dot.github.io/TASKING/`

## 卡牌資料

- 預設連到 `https://card-uploader.onrender.com/api/cards`
- Render 免費方案閒置會休眠，第一次打開卡包區可能要等 30–60 秒；任務清單本身不需要連線，隨時可以用
- 卡牌資料會快取在手機裡，下次打開先用快取，再在背景更新
- 想連到別的卡牌伺服器（例如本機測試）：在網址加上 `?api=http://localhost:3000`

## 存檔

所有任務、卡包、卡牌收藏都存在瀏覽器的 localStorage（`tasking.save.v1`），只存在這支手機／這個瀏覽器裡；
清除網站資料就會重新開始。和 CardKing 的存檔是分開的。

## 調整數值

- 每包張數、卡包系列（`packSet`）、黃光／彩虹光的稀有度門檻：`js/data.js` 最上面的 `RULES`；卡包顏色是 `PACK_THEME`
- 抽卡權重：`js/data.js` 的 `RARITY_WEIGHT`；型態機率：`VARIANTS`
- 能量條格數固定 10 格

## 檔案

```
index.html        頁面骨架
css/app.css       任務清單的樣式（白底、手寫字、麥克筆線條）
css/cards.css     卡牌、卡包、開包舞台的樣式（來自 CardKing）
js/main.js        畫面：首頁、資料夾、編輯模式、卡包區、我的卡牌
js/store.js       存檔：資料夾、任務、卡包、收藏
js/marker.js      麥克筆風的框、勾選框、能量條、圖示
js/sortable.js    長按拖曳排序
js/data.js        連線卡牌製造機、抽卡、開卡包
js/opening.js     開卡包動畫（來自 CardKing）
js/crayon.js      蠟筆風的卡牌、卡包繪製（來自 CardKing）
js/particles.js   彩紙粒子（來自 CardKing）
js/sfx.js         合成音效（來自 CardKing）
js/util.js        小工具
```
